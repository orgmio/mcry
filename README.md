# mcry
A semi-decentralized, fast, and secure free download protocol.
## 🚀 Features
- **Simple**: A download link can be generated with just a few simple lines of commands.
- **Fast**: The traditional downloading method relied on a single server, but now a single server notifies other downloaders to upload for you.
- **Privacy**: They remain anonymous and do not disclose their IP addresses; the data is encrypted using a modified version of Reality.
- **Freedom**: It is completely open source and belongs to free software.
## 🔧 How to use?
input
```bash
./mcry -c ./path/to/file
```
output(like this)
```bash
mcry://r2.867678.xyz/qcsh.mcry
```
