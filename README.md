# MCRY
A semi-decentralized, fast, secure and open source download protocol.
## 🚀 Features
- **Simple**: A download link can be generated with just a few simple lines of commands.
- **Fast**: The traditional downloading method relied on a single server, but now a single server notifies other downloaders to upload for you.
- **Privacy**: They remain anonymous and do not disclose their IP addresses; the data is encrypted , just like you really visit the real server.
- **Freedom**: It is completely open source and belongs to free software.
